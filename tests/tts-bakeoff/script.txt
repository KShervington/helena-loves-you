# proof
A repository gained forty thousand stars in six days. It is called Moondream, version two. A vision model small enough to run on a laptop GPU. Observe how.

# mechanism
A vision model cannot look at a picture. So it divides the image into two hundred and fifty-six tiles. Like a photograph cut into pieces. Nothing is lost. Only reordered. Each tile becomes a number. A word, to the machine. So the picture becomes a sentence, and the language model reads it.

# observation
That is not the interesting part. It does not read every tile the same way. It attends where the picture is busy, and almost nowhere else. The sky costs it nothing.

# resolution
That is why it stays small, and stays right. It is not seeing the image. It is reading it. You can do this too, in a different way. You already do.
